Frontend, backend, route and design migration

Implementation report for the React/Vite application and the supplied public_html design references.

Architecture

Frontend

React 19 + TypeScript + Vite. Zustand owns SPA screen state. SCSS is composed through src/styles/app.scss.

Backend

Express + TypeScript + Supabase service-role API. Role authorization is enforced by middleware and server routes.

Reference site

Original public_html files remain intact and are served independently on port 4174.

SPA and navigation

Browser path or deep link→React SPA shell→Zustand screen state→Role workspace when authenticated

Existing browser paths and client-side navigation are preserved. React navigation does not mutate the address bar. The separate reference server retains its original .html URLs.

Visual system

Color

Aqua primary actions, deep teal ink, mint status surfaces, pale paper background, yellow focus accents, and coral exception states.

Typography

Manrope for interface text, DM Mono for labels and eyebrows, expressive display scale for hero sections.

Surfaces

Low-radius cards, fine teal borders, restrained shadows, dark featured panels, responsive grids, and visible focus states.

Motion

Existing reveal, hover lift, loading skeleton, tracking pulse, and reduced-motion support are preserved.

Responsive UI

Desktop multi-column layouts collapse to one column at mobile widths; workspace navigation becomes a drawer.

Accessibility

Skip links, semantic headings, labelled controls, keyboard buttons, focus outlines, status messages, and validation states.
