Pending work by execution order

  1. Production deployment: deploy frontend/backend, configure TLS, domain, environment secrets, CSP, logging, health checks, rollback, and rate-limit monitoring.
  2. Payment validation: run a controlled Razorpay test payment, verify signature and webhook persistence, then test refund/reconciliation.
  3. Realtime validation: keep customer and vendor browsers connected, create a booking, accept it, and confirm the UI receives the event without refresh.
  4. Provider validation: configure and verify email, SMS OTP, WhatsApp, storage proof uploads, and VAPID push if push notifications are in scope.
  5. Session hardening: prevent protected workspaces from rendering until authentication hydration and token validity are resolved.
  6. Admin mutation testing: validate booking status changes, vendor approval, service/pricing changes, and audit records with controlled retained test data.
  7. Quality gates: add focused route authorization tests, component tests, accessibility checks, and a repeatable Playwright smoke suite.
  8. Analytics operations: define event taxonomy, retention/anonymization rules, alerting, and KPI dashboards before collecting production-scale traffic.
  9. Final release review: verify backups, RLS policies, secrets, monitoring, incident runbook, support contacts, and rollback procedure.
